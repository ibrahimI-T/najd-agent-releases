# NAJD AGENT releases (old channel)

This repository carried NAJD AGENT's installers up to version 0.10.4. New versions are published in the main repository:

**Download the latest NAJD AGENT:** https://github.com/ibrahimI-T/najd/releases/latest
or from the website: https://najdagent.si

If you installed NAJD from here, download the new installer from one of those links and run it. Your chats and settings stay where they are.
